## 官网为什么搜不到"Lite"

DMIT 后来统一了产品线命名，原来的 Lite 归到 Tier 1 体系，官方不再使用 Lite 这个词。线路本身没有跟着改名变化，仍是多家 Tier 1 运营商组成的国际 BGP，卖点是大带宽、大流量、香港原生 IP，能解锁 Netflix 港区。

对大陆方向它不做任何专项优化。这一点决定了它适合谁：境外访问、国际建站、需要香港 IP 做落地、配合广移或 IPLC 之类的中转方案使用，这些场景 T1 很划算。把它当国内直连的代理机，体验会让你怀疑买错了产品。

## T1 的真实表现：移动能看，电信劝退

综合几份第三方整理，三个运营商分化明显：

- **移动**最好，经 CMI 直连香港 NTT，延迟常在 50ms 出头，跑落地流畅度不错
- **联通**居中，去程绕日本 NTT，回程比电信好，做落地还能接受
- **电信**最差，路由可能绕新加坡再进香港，延迟 200ms 以上，丢包率也高于另外两家

所以电信用户如果主力用途就是从国内直连这台机器，T1 基本不用考虑，往上加钱上 EB 或 Pro 更实在。有中转方案的另说，落地机不挑回程，T1 的性价比优势就出来了。
